# EXEMPLARS — what a finished LMCAD part campaign ships

Digest for design agents who have NOT read the source docs. Built from the two
finished campaigns (`showcase/squatchee_spin/` — JSON-program style, published on
Printables with 1.2K downloads; `camera_system/card_magazine/` — Rust-example
style, 35 gates) plus `campaign/friction/ENGINE.md` and `docs/FIELD_REPORTS.md`. Every
command line and JSON shape below was verified against the live tree on
2026-08-06 by running it, not paraphrased.

**The house law, in one line:** every claim in prose must trace to a machine
receipt; every retention/safety claim must have a measured negative control; and
everything NOT analysed is listed by name under "Required, NOT performed" — never
silently omitted.

Pitfalls, verified:
- `kernel-api` with no subcommand prints usage and exits 1. Always `run` or `asm`.
- `production_dossier.py`, `render_sheet.py`, `assembly_doc.py` have **no
  `--help`** — they treat `--help` as a filename and crash. Read the docstring at
  the top of each tool file instead (`head -40 tools/<tool>.py`).
  `tolerance_stack.py` and `sweep_check.py` do print their docstring.
- **The engine ignores unknown JSON params silently.** A typo'd param name does
  not error — it is simply dropped, and your intent silently vanishes. Verify
  every param name against `API.md` or a run receipt. (Campaigns exploit this
  deliberately: top-level `"part"`, `"notes"`, `"assembly"`, `"receipts"`,
  `"_why"` keys are ignored by the engine and used as an embedded design record.)
- `export_stl` `"file"` paths are relative to `--out-dir`.
- Relative `load_part` paths resolve against the PROGRAM file's directory
  (FRICTION #13, resolved) — programs are relocatable.
- One engine binary, one wire: `./target/release/kernel-api run <program.json>
  --out-dir <dir>` prints the whole report on stdout (`param_optimize.py` /
  `sweep_check.py` drive it one-shot internally).

### Program receipt shape (verified by running `retainer_program.json`)

Top level: `{"api_version": "cadcode.v1", "ok": true, "ops": [{"id", "ok", "measures"?, "error"?}, ...]}`.
Execution stops at the first failing op; exit code follows `ok`. Key measures:

| op | measures (exact keys) |
|---|---|
| `validate` | `valid, manifold, closed, shells, genus, euler_characteristic, geometric_ok` |
| `mass_properties` | `center_of_mass, inertia_diag, inertia_tensor, provenance, …` |
| `bounding_box` | `min, max, center, size, diagonal` |
| `support_report` | `support_free, steep_area, bridge_area, max_bridge_span, bed_area, total_area, provenance` |
| `export_stl` | `route` ("exact"/"voxel_healed"), `triangles`, `watertight` |
| `clearance` | `distance, interfering, overlap_volume, coincident_fit_hazard, provenance` |
| `sketch` | constraint-solver state: `converged, dof, state, residual, …` |

Per-part program skeleton (all three parts follow it):
build ops → `validate` → `mass_properties` → `bounding_box` →
`support_report {build_dir: [0,0,1]}` → `export_stl {file, tol: 0.01}`.
The top-level `"part"` and `"notes"` strings carry the full design rationale —
including load-bearing warnings like the propeller's *"BOOLEAN ORDER IS
LOAD-BEARING: bore cut on the VIRGIN hub cylinder first, blades fused b1+b2, hub
merged LAST — other orders leave sliver facets on the fused coplanar bottom face
(geometric_ok false)"* and *"47-pt polygon, min segment 1.5 mm — denser sub-mm tip
chords left sliver facets → geometric_ok false"*. Write yours the same way: the
program file IS the design record.

The assembly program embeds an informal `"receipts"` block at top level (engine
ignores it) holding the expected measured values — `c_prop_mount_mm: 0.200001`,
`retention_negative_control: {interfering: true, overlap_mm3: 0.0263, meaning:
"lug bears on the pocket ledge - positive retention"}` — so a re-run can be
diffed against the shipped claim.

## 2. The gate taxonomy actually used

The card_magazine suite is **35 gates** + a per-part emit audit (valid,
watertight, single-body, steep area, bridge span, printed per part). Squatchee
runs the same classes through JSON programs + Python tools. The classes:

### 2.1 Geometry validity
- `validate`: `valid`, `manifold`, `closed`, `shells`, `genus`, `geometric_ok`
  all checked (squatchee: every part program; magazine: emit audit).
- **Connectivity is TWO separate oracles, and you must gate BOTH** (FRICTION
  #24, corrected 2026-08-08): `valid` + `watertight` + a volume window can all
  pass on a part in two floating pieces. Gate `assert shells:1` (exact B-rep)
  **and** `assert components:1` (union-find over the tessellated mesh's welded
  vertices — the drill_hook idiom). The old claim that "`shell_count` lies
  while `mesh_components` tells the truth" is **retracted**: on this kernel a
  `difference`-severed bar reads `shells 2` AND `components 2`, a sub-weld-tol
  sever reads `shells 2` but `components 1` (only `shells` fires), and
  `extrude_with_holes` reads `shells 1` while `mesh_components` REFUSES
  (`invalid_geometry`; it used to false-alarm with 3). Ship **two** oracle-NCs, one per direction —
  copy-ready programs in `DELIVERABLE_SPEC.md` §2.13, both verified to exit 1.
- In-program assertions exist: `assert` (volume_within, genus, shells, closed,
  manifold, valid) and `assert_disjoint {a, b, min_clearance?}` — exit-1 on
  unmet intent. Use them; a recorded-but-unchecked measure is worthless in CI.

### 2.2 Printability
- `support_report` with an explicit `build_dir`: gate `steep_area == 0.0`
  exactly (squatchee ships "steep area exactly 0.0 on all three parts, worst
  micro-bridge 2.82 mm"; magazine "0.00000 mm² steep, one 11.6 mm bridge — the
  captive-nut pocket roof"). "Support-free" is a machine-audited claim.
- Wall/feature vs process: magazine gates `divider walls ≥ 1.6` (= exactly 4
  perimeters at a 0.4 nozzle), bed fit (`≤250 mm`), and even "body is majority
  void" (≤55% of envelope) so the machining path is sane.
- Mass thresholds need an EXTERNAL reference or they are just picked numbers:
  the magazine's is "weighs less than the media it carries" (6 × 12 g cards).

### 2.3 Fit stacks at printer extremes (±0.15 mm XY is the house FDM default)
- `tolerance_stack.py` FIT mode: squatchee pivot Ø7.2 bore / Ø6.6 sleeve →
  clearance [0.30, 0.90] mm across ±0.15 extremes, `interference_at_extremes:
  false` — "binding impossible" is a computed sentence.
- CHAIN mode with `closes {min_required, max_allowed}`: grip capture on the
  smallest 14 mm button (min 0.1 mm), 3-term axial float chain (0.05–1.2 mm).
- Magazine does it in-suite: slot clearance gated at nominal card (0.4–0.9) AND
  worst-case thick card (3.95 → >0.3); rib interference gated both by arithmetic
  (0.05–0.35) AND by `penetration_estimate` on a **posed** card mesh — never
  trust arithmetic alone when you can measure the modelled geometry.
- Deliberate interference is a fit spec too: well-rib 0.20 mm bite is a designed
  grip, shelf-rib 0.10 mm clearance is a guide — both gated in-range, not just
  ">0".
- Where nobody publishes the tolerance (CFexpress thickness scatter), ship a
  **fit coupon** and say the number is community-reported.

### 2.4 Motion / insertion sweeps (free-run proofs ONLY)
- `sweep_check.py`: squatchee's 18-station retainer descent, 9-station twist,
  14-station prop drop — pass = `interfering false` and constant clearance at
  every station; the CSVs are shipped receipts.
- **Blind spot (FRICTION #27): a sweep cannot see a STEADY interference** that
  never produces a near pose (`crossings == 0` on a gauge that interferes 1 mm
  everywhere). Rule: sweeps prove things move freely; anything asserting
  something does NOT fit belongs on the exact `overlap_volume` oracle.

### 2.5 Negative controls for retention claims — see §3.

### 2.6 Standards conformance & refusal gates
- Magazine gates every ARRI Pin-Lock number against the published drawing: LK
  Ø10.4 / 45°, hole depth ≥5.2, ream stock 0.10–0.20, max stud protrusion 7.5
  doesn't bottom, dowel proud length 4.0–4.8 (ARRI's max).
- **Refusals are gated, not stated as preference**: "heat-set insert REFUSED:
  its boss (Ø19.0 by the 2×-diameter rule) would eat the Ø10.4 pin ring" is a
  passing gate that PROVES the rejected alternative is geometrically impossible.
- **Measure the modelled geometry, not the constructor's intent**: the gate that
  caught the shipped hex-pocket bug measures the actual polygon's Y-extent and
  asserts it equals across-flats (11.62), not across-corners (12.94). The nut
  physically could not enter before that gate existed.

### 2.7 STEP / export fidelity
- `coalesce_coplanar` before STEP export (boolean chains fragment planar faces
  — a 72 mm part's raw STEP was 4.45 MB of edge bookkeeping), gated: volume
  drift < 0.001%. Then STEP round-trip re-import gated: volume conserved < 2.5%
  (magazine measures 0.000%). `export_stl` receipts should say `route: "exact"`;
  `voxel_healed` is honest fallback but a fidelity note.

### 2.8 Sustained-load (creep, not static)
- A part that hangs on a rig for days is judged against the **time-derated creep
  table** (`kernel_model::materials::pla::creep_allowable_mpa(23.0, 8760.0)` =
  2.5 MPa at 23 °C/1 yr), not the static allowable. Magazine: 1.31 N over the
  73 mm² nut seat = 0.0181 MPa → ~138× margin, gated at ≥50×.
- Spring parts get strain gates instead: squatchee's PETG fingers gated ≤1.72%
  snap-over strain (with material choice made FUNCTIONAL in the BOM:
  `material_required: true` = "PLA here is brittle and may crack").

### 2.9 Balance (rotating parts)
- `balance_check.py` over `mass_properties`: squatchee prop CG 1.8e-9 mm off
  axis → 0.0 g·mm static imbalance, couple terms 0.0 g·mm² — achieved by
  construction (exact y-mirror + 180° blade symmetry, axisymmetric bore) and
  then *measured*, with "symmetric infill preserves balance" carried into the
  print settings.

## 3. The negative-control doctrine

**A retention/safety claim is only falsifiable if you also build the pose where
it must FAIL, and measure it.** Both campaigns follow the same three-part
pattern:

1. **The failure attitude must measurably interfere.** Squatchee
   `c_retention_neg`: retainer lifted +0.15 past engagement WHILE LOCKED →
   `interfering: true, overlap_volume: 0.0263 mm³` (verified live). "If this
   ever comes back clean, the part can fall off and the claim is dead."
   Magazine: a SHOT card driven horizontally toward FRESH penetrates the shelf
   face by **3.00 mm** — no horizontal path exists.
2. **The twin release/legal-path control must measurably clear.** Squatchee
   `c_release`: same lift, windows UNTWISTED → `interfering: false, distance:
   0.1488 mm` — serviceability proven. Magazine NC: the same card lifted to
   shelf height crosses the identical path with `pen 0.000, contacts 0` — which
   proves the interlock gate "can pass and is not measuring a self-fulfilling
   collision."
3. **Use the exact oracle, in the exact failure attitude.** Overlap volume of
   posed solids, not sweep verdicts (FRICTION #27), not spring-force hand
   waving. v2 of squatchee explicitly moved retention from spring interference
   to geometry so that "printer tolerance can't weaken it: the lock is geometry,
   not spring pressure" — and then measured the geometric interference anyway.

Corollaries recorded in FRICTION:
- Build NCs for **oracles**, not just parts — and one per DIRECTION when two
  oracles are complementary. drill_hook's split-body NC pins that `components`
  fires on a coarse sever; it takes a **second** NC (a 0.0005 mm sever, where
  `components` passes and only `shells` fires) to prove the two are not
  redundant. `DELIVERABLE_SPEC.md` §2.13 (#24, corrected 2026-08-08).
- **An inverted negative control is a design alarm**: when the deliberately
  under-built (40% thickness) FEA control came out STIFFER than the shipped
  part, the shipped geometry was wrong (a voxel grid was losing a thin
  structural tie) — the NC diagnosed it (#26).
- When the oracle refuses at an NC pose (`overlap_volume` → NaN at one offset,
  #25), pick a neighbouring offset that resolves and **record the refusal in
  DESIGN.md** rather than silently stepping around it.
- Ship both controls' numbers in the public listing. Squatchee's marketing copy
  literally quotes them — "receipts as marketing" is the house publish style.

## 4. Top process lessons (campaign/friction/ENGINE.md + docs/FIELD_REPORTS.md) — do not repeat

1. **Green ≠ whole.** `valid` + `watertight` + every dimensional gate can pass
   on a part in TWO PIECES (`shell_count` counts B-rep records, not connected
   geometry). Gate mesh connectivity on every part, especially after any
   tapered/shrinking cutter; keep the cutter apex strictly inside material with
   a named margin constant (FRICTION #24, drill_hook's `END_TIE`).
2. **Size structural ties ≥ ~2 cells of whatever grid will analyse them.** A tie
   the FEA voxel grid can lose is a tie slicer perimeters can lose. A 2.5 mm tie
   read 5× softer on a 2.0 mm grid; 5.0 mm fixed it. Exact-vs-discretized
   disagreement is a design finding, not solver noise (#26).
3. **Float contact poses by 0.1 mm** (§7.4): a part resting EXACTLY on a surface
   is a coincident-face degeneracy — the magazine's first NC run read 12 kissing
   contacts until the card was floated +0.1. Same family: never place a planar
   face exactly tangent to a curved wall (refused by `try_difference`).
4. **Boolean order and polygon quality are load-bearing.** Cut holes on virgin
   primitives before fusing coplanar-bottomed bodies; keep polygon segments
   ≥ ~1.5 mm (sub-mm chords → sliver facets → `geometric_ok: false`). Ease
   edges (fillet/chamfer) on primitives before booleans, or run
   `coalesce_coplanar` (provenance now survives it, #20).
5. **Empty booleans are loud failures BY DESIGN.** Don't prove disjointness by
   intersect-and-hope; use `assert_disjoint {a,b,min_clearance}` or
   `union_all` + `assert {shells: N}` (#4/#5/#16 — all resolved into real ops).
6. **`min_thickness` is corner noise.** Use `thin_area`, `p05_thickness`,
   `median_thickness` (#17). The hole wizard has no edge-proximity warning —
   gate `wall_thickness` + a volume window after every wizard cut (#21).
7. **Measure the modelled geometry, don't trust the constructor.** Two shipped
   defects (hex nut rotated 30° = unassemblable; dowels 4 mm too short =
   decorative anti-twist) passed all early gates and were caught only by
   inspecting the printed geometry — then turned into permanent gates. Every
   defect found late must become a gate so it cannot recur.
8. **Solver refusals are data.** `ace_fea` refusing to converge at some voxel
   sizes, `overlap_volume` refusing at one offset, checked booleans refusing
   sliver overlaps — record the refusal in DESIGN.md/ANALYSIS.md and route
   around it visibly. Never launder a refusal into a skipped analysis.
9. **Write DESIGN.md BEFORE trusting geometry (§25.7); generate ANALYSIS.md
   EVERY run.** Frozen-dimension tables with per-row provenance; the analysis
   plan enumerated up front with every row later answered "gated, measured" or
   "required, NOT performed". Prose goes stale silently — the 2026-07-30
   FRICTION note records a doc claim that stayed wrong for 3 weeks because "a
   prose 'in progress' is not a mechanical claim." Generated docs cannot.
10. **Name what you did NOT do.** Both campaigns carry explicit not-done lists
    (shake/drop retention, thermal, rib fatigue — "printed-PLA across-layer
    fatigue data does not exist," so cycle life is *unclaimed*). Physical tests
    have no solver substitute; say so.
11. **Field loop: a field failure that does not become a gate is a lesson
    lost.** Intake via `tools/field_report.py` (loud refusals for evidence
    gaps), triage via `tools/field_triage.py` (mode → solver → re-derate → new
    gate; P0 = a green gate contradicted). A part run outside its material
    envelope (PLA above 55 °C) is a **condition violation**, never laundered
    into a design failure. The shipped corpus is 100% synthetic `EXAMPLE-`
    records — any claim citing real field failure rates from it is fabricated.
12. **Squatchee's v2 is the field loop working**: three user complaints, all
    three fixed at the ROOT (split snap-post → solid post + bayonet; retention
    moved from spring to geometry; every non-spring wall ≥2 mm at LOWER spring
    strain), with the honest trades stated (heavier, firmer snap) and "matched
    set — no v1/v2 mixing" declared.
13. **Publish honestly.** The card_magazine listing opens with a warning that
    the contest bans AI-generated models and that this design IS AI-generated —
    do-not-submit-as-is, with the honest options enumerated. Form limits
    (120-char summary, lowercase space-separated tags) were verified on the
    live site and pinned by `publish/check_listing.py`. Copy every number in
    the listing from a receipt.
14. **Determinism doctrine**: sheet/doc generators take `date` as an input and
    never read the clock — same job, byte-identical PNG; the boolean pipeline is
    run-deterministic, so committed STLs must regenerate byte-identical.
